# Official court forms

The published forms themselves, used as the template for court document
precedents rather than a layout reconstructed in code.

## Why they are here

A court document is filed under a prescribed form. Rebuilding that layout by
hand gets the words right and the document wrong: the real UCPR Form 3A is 12
tables and 77 rows, and a reconstruction drifts from it every time the form is
amended. Filling the published file instead means the layout is the official
one by construction.

Every NSW form except Form 40 is published as a Word 97-2003 `.doc`. Those were
converted once to `.docx` through the LibreOffice service in `docservice/`
(`diract-docservice.fly.dev`), because conversion takes about 26 seconds and
cannot sit in the path of a user waiting for a download. macOS `textutil` is
not a substitute -- it flattens every table.

## Staying current

`.github/workflows/court-forms-check.yml` re-downloads each `sourceUrl` daily
and compares it against `sourceSha256` in `manifest.json`. If a form has been
amended it opens (or comments on) a `court-forms` issue. Run it by hand with:

```
npx tsx scripts/checkCourtForms.ts
```

The comparison is against the file **as published**, not against our stored
copy: most forms are published as `.doc` and we store a converted `.docx`, and
conversion is not reproducible byte-for-byte, so comparing our own output would
alarm every run.

When a form does change:

1. Download the new form from its `sourceUrl`.
2. Convert it to `.docx` if it is published as `.doc`.
3. Replace the file here, and update the version in the table above **and** in
   the precedent's `reviewNote` in `lib/precedents/library/`.
4. `npx tsx scripts/checkCourtForms.ts --adopt` to record the new hash.
